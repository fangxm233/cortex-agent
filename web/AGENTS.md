Responsive web UI with browser, desktop and native mobile integrations.

| filename | role | function |
|---|---|---|
| src/ | core | Render UI and adapt device capabilities |
| scripts/ | tooling | Build and check frontend boundaries |
| public/ | assets | Supply static application assets |
| index.html | entry | Start the web application |
| package.json | config | Declare frontend commands and dependencies |
| tsconfig.json | config | Configure frontend type checking |
| vite.config.ts | config | Configure bundling and scoped tests |
| tailwind.config.ts | config | Configure utility styles |
| postcss.config.js | config | Configure CSS processing |
| .dependency-cruiser.cjs | config | Declare frontend import boundaries |
| .dependency-cruiser-known-violations.json | config | Record existing import boundary exceptions |
