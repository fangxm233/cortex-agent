Text rendering helpers of the terminal client for markdown and rich message blocks.
They turn message content into styled terminal output.

| filename | role | function |
|---|---|---|
| inline-markdown.tsx | view | renders inline markdown as styled text |
| markdown.ts | core | parses inline markdown into typed segments |
| rich-blocks.tsx | view | renders rich block arrays as text elements |
