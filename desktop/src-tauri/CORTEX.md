Rust crate configuration and build entry for the native shell.

| filename | role | function |
|---|---|---|
| Cargo.lock | lock | Locks resolved dependency versions |
| Cargo.toml | config | Defines Rust crate metadata and dependencies |
| build.rs | build | Runs the Tauri crate build script |
| tauri.conf.json | config | Configures tauri.conf |
| capabilities/ | directory | Contains Tauri capability manifests |
| icons/ | directory | Contains application icon assets |
| src/ | directory | Contains production source modules |
